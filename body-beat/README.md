# BODY BEAT（全身 AR 音ゲー・プロトタイプ）

カメラに映った自分の体の周りに、音楽に合わせてノーツが流れてきます。
手・足・体を動かしてノーツにタッチする音楽ゲームです。
**ノーツの並び自体が振り付け**になっていて、ノーツを取っていると自然に踊っているように見えることを目指しています。

- ブラウザだけで動きます（PC の Web カメラ・スマホのインカメラ）
- 骨格認識：MediaPipe Pose Landmarker（lite モデルを同梱）
- アカウント・データベース・通信は使いません（映像は端末の中だけで処理します）

## 遊び方

1. START を押す → カメラの使用を許可する
2. 全身が映るように、カメラから 2〜3 m 離れて立つ（足まで映ると「OK！」）
   - 上半身しか映らないまま 5 秒たつと、そのまま始まります（足のノーツは腰を左右に動かせば取れます）
3. 3・2・1・START！
4. 曲が終わるとスコアが出ます →「もう一度遊ぶ」

## ノーツ

| ノーツ | 見た目 | 取り方 |
|---|---|---|
| HAND | 水色の ✋（左手）／ピンクの ✋（右手） | その色の手でタッチ。高い・低い・外側・内側に出る |
| BOTH | 金色の 👏（大きめ） | 両手をそろえてタッチ（クラップ） |
| CROSS | 点線の輪つきの ✋。肩から点線が伸びる | 体の反対側に出る。点線が出ている側の手で取る（体がひねられる） |
| TRACE | 光る道筋＋動く玉 | 玉を手で追いかけてなぞる |
| STEP | 緑の 👣（足元） | その足でふむ（または、その方向へサイドステップ） |
| POSE | 画面上部の人の形のアイコン | 同じポーズをとる（両手を上げる／広げる／左右に傾く） |

- ノーツは外側から近づいてきます。周りの輪が縮んで、本体に重なった瞬間がタイミングです
- 判定は PERFECT／GOOD／MISS。精密さより気持ちよさを優先して、ゆるめにしています
- ノーツを取ると、クラップ・キック・スネア・ベル・シンセなどの音が曲に重なります（早めに取っても拍ぴったりに鳴ります）

## テスト用のモード（URL の後ろに付ける）

| URL | 内容 |
|---|---|
| `?debug` | 骨格・FPS・経過時間を表示 |
| `?bot` | カメラなしで、仮想ダンサーが自動で遊ぶ（譜面どおりに動くと踊って見えるかの確認用） |
| `?mouse` | `?bot` と同じだが、右手をマウスで動かせる |

## 譜面（振り付け）

`src/chart.js` にあります。位置は「体の単位」で書きます。
- 原点：両肩の中心
- 1：胴の長さ（肩〜腰）
- x：右が＋（画面は鏡なので、プレイヤーの右手側が画面の右）
- y：上が＋

体格やカメラとの距離が変わっても、同じ振り付けになります。

| 部分 | 小節 | 振り付け |
|---|---|---|
| イントロ | 0〜3 | 左右交互の HAND で体を揺らす |
| A1 | 4〜7 | 左右交互・横と斜め上 |
| A2 | 8〜11 | 右上→左下→左上→右下の対角線、最後に胸の前で BOTH |
| ビルドアップ | 12〜15 | STEP と同じ側の HAND（ステップタッチ）→ 頭上の BOTH → POSE（両手を上げる） |
| メロディー | 16〜19 | 右手・左手の TRACE（下から上へ大きな弧） |
| サビ | 20〜27 | HAND（外へ）→ CROSS（ひねる）→ STEP → HAND の組み合わせ。最後に POSE（両手を広げる） |
| 間奏 | 28〜29 | 左右に体を傾ける POSE |
| ラスト | 30〜35 | 大きな TRACE（右・左）→ BOTH ×2 → 決めポーズ |

全 83 ノーツ。16 分音符のような速いノーツはありません。

## 曲

### いま入っている曲
**仮の曲**：動作確認のため、プログラムで作ったファンク調の曲（112 BPM・約 84 秒、`src/tempSong.js`）です。
ライセンス上の問題はありません。

### 本物の曲に差し替える
1. 曲のファイルを `public/music/` に置く
2. 解析ページでテンポと 1 拍目の位置を調べる：`npm run dev` で開いて `/scripts/analyze.html?file=/music/ファイル名.mp3` を開く
3. `src/chart.js` の `song` の url・bpm・offset・lengthBeats・title を書き換える
4. 曲の構成に合わせて譜面の小節割りを調整する

### 使用楽曲
（本物の曲に差し替えたら、曲名・作者・出典 URL・ライセンスをここに書く）

## 手元で動かす

```bash
cd body-beat
npm install
npm run dev
```

カメラは `https://` か `localhost` でしか使えません。スマホで試すときは Netlify などに公開してください。

## Netlify に公開する

MONSTER GO と同じように、**別のプロジェクト**として作ります。
- Base directory：`body-beat`
- Branch to deploy：`main`

データベースや環境変数は不要です。

## ファイル構成

```
body-beat/
├─ index.html            画面（タイトル・準備・カウントダウン・結果）
├─ src/
│  ├─ main.js            全体の流れと毎フレームの処理
│  ├─ chart.js           曲の設定と譜面（振り付け）
│  ├─ game.js            判定・スコア・コンボ
│  ├─ render.js          ノーツ・演出・HUD の描画
│  ├─ body.js            画面の座標変換と「体の単位」の座標系
│  ├─ pose.js            カメラと骨格認識
│  ├─ audio.js           曲の再生（ゲームの時計）と効果音
│  ├─ instruments.js     プログラムで鳴らす楽器
│  ├─ tempSong.js        仮の曲
│  └─ bot.js             自動で遊ぶ仮想ダンサー（?bot）
├─ public/models/        骨格認識のモデル
├─ public/music/         曲の置き場所
└─ scripts/              MediaPipe のファイルのコピー、曲の解析ページ
```
