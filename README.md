# SUBMERGED CITY

夕暮れの水没した小さな街を、自由に泳いで探索するブラウザ3D作品。
目的・スコア・戦闘はなく、水・光・空気感と「泳いでいて気持ちいいこと」だけに集中しています。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
npm run preview  # ビルド結果の確認
```

## Netlify へのデプロイ

`netlify.toml` 設定済みです。GitHub リポジトリを Netlify に接続すれば、そのまま自動デプロイされます。

- Build command: `npm run build`
- Publish directory: `dist`
- Node: 22

## 操作

| | PC | スマートフォン |
|---|---|---|
| 泳ぐ | WASD / 矢印キー | 左側の仮想スティック |
| 視点 | マウス（クリックでポインタロック） | 右側をスワイプ |
| 浮上 | Space / E | ▲ ボタン |
| 潜水 | Shift / Q / C（下を向いて前進しても潜る） | ▼ ボタン |
| メニュー | ESC → ☰ | ☰ |

### ツアーモード（自動で街を巡る）
スタート画面の「ツアーで眺める」、またはプレイ中の「🧭 ツアー」ボタン（PCは `T` キー）で切り替えます。
ランドマークを通る一周ルートを自動で進み続けます。自分で操作するのは視線の向きだけです。

| | PC | スマートフォン |
|---|---|---|
| 見回す | マウスドラッグ | スワイプ |
| 視点：潜水艦 / 船 / 上空 | `1` / `2` / `3` | 画面下のボタン |
| 速度：一時停止 / ゆっくり / ふつう / はやい | `P`（一時停止）、`-` / `+` | 画面下のボタン |

- 視点や操作モードを切り替えると、約3秒かけて新しい位置へなめらかに移動します。
- 見回すのをやめると、数秒後に視線が進行方向へゆっくり戻ります。
- 左上のミニマップに、現在地と向き（矢印）、ルート、ランドマークの印を表示します。タップすると拡大します。

### 乗り物
遊具の近くまで泳ぐと「乗る」ボタンが出ます（PCは `F` キー）。「降りる」で乗った場所に戻ります。

- **メリーゴーランド** / **観覧車**（水中から水面の上まで一周） / **ジェットコースター**（水中と水上を何度も行き来）
- **コーヒーカップ**：右下のハンドルをぐるぐるドラッグすると自転が速くなります（PCは `A` / `D` でも）

### 写真・ムービー・ギャラリー
| | PC | スマートフォン |
|---|---|---|
| 写真モード | `O`（撮影は クリック / `Enter`、`G` フィルター、`H` 時間停止） | 📷 → シャッター |
| 録画（最長60秒・音声付き） | `R` | 🎥 |
| ギャラリー | `L` | 🖼 |

- マウスで視点を操作している間は、`ESC` でマウスを解除すると画面のボタンを押せます。
- 写真と動画はブラウザ内（IndexedDB）に保存されます。ギャラリーから端末へ保存・共有・削除ができます。

## 見どころ

- **水面**：カモの群れ、カモメ、スワンボート、ときどき跳ねる魚、跳ねるイルカの群れ
- **水中**：ジンベイザメ、エイ、ウミガメ、マンボウ（レア）、イカ、クラゲ、イワシの大群、熱帯魚、カニ、サンゴ・イソギンチャク・ヒトデ・ウニ。自分の周りに、深さに合った生き物が常に泳ぐ仕組み
- **深海の海溝**（水深約45m）：ホタルイカの群れ、チョウチンアンコウ、ハダカイワシ、光るクラゲ、リュウグウノツカイ（レア）、光るイソギンチャク
- **光と泡**：たくさんの光の筋と、水中から見上げたときに差し込む光（ゴッドレイ）。泡はガラス玉のような見た目で、海底から立ちのぼる泡の柱もある
- **遊園地「SUISUI LAND」**：乗れるメリーゴーランド・コーヒーカップ・観覧車・ジェットコースター、入場ゲート、チケット売り場、柵、ベンチ
- **日本の街角**：コンビニ、牛丼屋、半分沈んだ歩道橋、郵便ポスト、電話ボックス、カーブミラー、ガードレール、自販機
- **商店街**：八百屋、本屋（周りに本が漂う）、のぼり旗、吊り看板、シャッターの下りた店

## 構成

```
src/
  main.js               起動・ループ・UI・品質の自動調整
  globals.js            全マテリアル共通のuniform
  waves.js              Gerstner波（CPU側。GPUと同じ式）
  quality.js            HIGH / MEDIUM / LOW
  post.js               HDRシーンRT → 水中判定・フォグ・歪み・トーンマップ
  player.js / input.js  泳ぎの物理・キーボード/マウス/タッチ
  tour.js               ツアールート・3つの視点・速度・視点間のなめらかな移動
  minimap.js            ミニマップ（地形・道路・建物・ルート・ランドマーク・現在地）
  audio.js              Web Audio による合成サウンド（音声ファイルなし）
  shaders/common.js     波・空・ノイズ・コースティクスのGLSL
  world/                空・水面・地形・街・看板・マテリアル拡張（extras.js：街角と遊園地）
  fx/                   魚群・海藻・鳥・浮遊物・泡・粒子・光の筋・グロー
                        rides.js：遊具（観覧車・コースター含む）/ sealife.js：大型の生き物・水面の生き物・しぶき・漂う本
                        ambient.js：周囲に湧く生き物・深海生物・ホタルイカ / decor.js：海底のサンゴなど
  capture.js            写真・動画の撮影とギャラリー（IndexedDB）
```

使用技術: Vite / Three.js (r186) / GLSL / Web Audio API。追加ライブラリなし。
